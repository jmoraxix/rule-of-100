Owner feedback after using production. UI only; DB and RPCs unchanged.

**Done**

- Count goals: `+1` sits to the right of the number on the same row, large (height `clamp(6rem,26vw,10rem)`). No minus. Landscape count stays whole-screen `+1`.
- Timer goals: a visible Pause button next to the time, shown only while running. The big bottom button is Start (once a day) or Resume and is hidden while running. Landscape shows one visible Start/Pause/Resume button bottom-right.
- Timer shows a countdown: remaining = max(0, 6000 - elapsed) as `MM:SS`. Past 0 it shows `+MM:SS` counting up in the inverted overachieved state (same as count > 100). Exactly 0 is "Complete".
- At 0 (crossing while the screen is open) three 880 Hz beeps via Web Audio (oscillator, no files, no deps).
- Progress ring: thin SVG ring around the number on count and timer, portrait and landscape, filling clockwise (count value/100, timer elapsed/6000) with a small % under the number. Stays full above 100% and inverts with the overachieved state; no transition under `prefers-reduced-motion`. With the ring on, the numerals are smaller so they fit inside it.
- 50% sound: timer only, one 520 Hz beep when crossing 50:00 remaining on screen (the 0 sequence is three 880 Hz beeps). Same AudioContext and same silent-if-already-past-on-load rule.
- Settings (portrait nav): "Progress ring" and "Sounds" toggles, both on by default, saved in `localStorage` per device with try/catch and an in-memory fallback when storage is blocked. Landscape reads the same settings.
- No auto-stop at 0 and no server timer change (owner is deciding separately).
- All secondary text (action, Day X/100, streak, nav, labels, buttons) uses fluid `clamp()` sizes in portrait and landscape.
- Login: "Continue with Google" (`signInWithOAuth`, `redirectTo` = `/auth/callback`). Provider errors show inline until the owner enables it. `/auth/callback` already calls `exchangeCodeForSession(code)`, the same PKCE flow as the magic link, so no change there.
- `.gitignore`: `.playwright-mcp/`.

**Decisions**

- Landscape timer no longer toggles on tap anywhere: accidental taps on a nightstand paused it. The counter keeps the whole-screen tap because a stray extra `+1` is the intent there.
- Pause is a separate button instead of morphing the main one, so the action that must not be hit by accident is a deliberate target; Start/Resume stay the single big action when stopped.
- Countdown is display only: `value` stays accumulated seconds, so refresh, one-running-timer and the 6000 threshold are untouched.
- The beep fires only on an on-screen crossing (previous rendered value < 6000, now >= 6000). A page that loads already past 0 stays silent, so it plays at most once per day.
- The AudioContext is created/resumed in the Start/Resume tap handler: browsers require a user gesture.
- Sound cannot play while the phone is locked or the tab is in the background (audio and timers are suspended there). Keep the screen on (landscape Wake Lock) to hear it. Not solvable without notifications (out of MVP).
- `.btn` sets `min-height` in unlayered CSS, which beats Tailwind utilities, so the big buttons set `h-[...]` instead.

**Not verified**

- The beep and the 0 crossing were not exercised in a browser (would need 100 minutes or a clock hack).
- Google flow not tested end to end: the provider is disabled until the owner enables it.
