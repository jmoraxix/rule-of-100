`curl -sI /icon.svg` returned 307 to `/login`, so signed-out pages had no favicon. Cause (confirmed):
the `src/proxy.ts` matcher only excluded `_next` and `favicon.ico`, so `/icon.svg` went through the
auth gate.

**Done**

- Matcher now also skips `icon.svg`, `apple-icon*`, `robots.txt`, `manifest*` (and keeps `favicon.ico`). Every other route stays protected.
