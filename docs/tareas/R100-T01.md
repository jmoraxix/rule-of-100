Minimal app skeleton plus the verification gates, so later tasks have real commands to run.

**Done**

- Next.js 16.3.8 (App Router, TypeScript strict, Tailwind 4, ESLint, `src/`) with pnpm at the repo
  root. Starter page replaced by a monochrome placeholder (black on white, white on black under
  `prefers-color-scheme: dark`). Starter assets (`public/*.svg`, favicon, Geist fonts, README) removed.
- `supabase` CLI 2.119.0 as devDependency; `supabase init` (`project_id = "rule-of-100"`, default
  ports); empty `supabase/migrations/`; pgTAP smoke test `supabase/tests/smoke.test.sql`.
- Scripts: `dev`, `build`, `lint`, `typecheck`, `db:start`, `db:stop`, `db:reset`, `test:db`.
- CI `.github/workflows/ci.yml` on `pull_request` and push to `main`: frozen install, typecheck,
  lint, build, then `supabase/setup-cli` + `supabase db start` + `pnpm test:db`.
- `CLAUDE.md` Status → Commands; `docs/proyecto.md` Verification commands updated.

**Decisions**

- `AGENTS.md` committed with Next's managed block and imported from `CLAUDE.md`: `next dev` writes
  that block into `CLAUDE.md` otherwise, which would dirty the tree on every run. It also points
  agents at the bundled Next 16 docs.
- Root layout types `children` explicitly instead of the global `LayoutProps`: that type is
  generated into `next-env.d.ts`/`.next/` (both gitignored), so `tsc --noEmit` on a fresh checkout
  would fail before `build`.
- No Google fonts: system font stack, no build-time network fetch.
- `.gitignore` ignores `.env*` (covers `.env`, `.env.production`, `supabase/.env`), keeping `!.env.example`.
- CI workflow sets top-level `permissions: contents: read` (least privilege for `GITHUB_TOKEN`).
- `poweredByHeader: false` in `next.config.ts` drops the `X-Powered-By: Next.js` header.
- `onlyBuiltDependencies: [supabase]` in `pnpm-workspace.yaml`: pnpm 10 blocks postinstall scripts
  and the CLI downloads its binary in one.
- CI uses `supabase db start` (Postgres only) instead of the full stack: pgTAP needs only the DB.
- Default Supabase ports kept: no container on 54320–54329 at the time of the check.
